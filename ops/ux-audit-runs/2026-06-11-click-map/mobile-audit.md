# Mobile Audit

Mobile/tablet screenshots: 1344
Mobile-related issues: 685

## Summary

- Mobile navigation must keep workspace, role, active section, and back path visible without creating an endless drawer.
- Filters should stay compact and move into sheet/drawer patterns on mobile.
- Parent/student bot/help should be a sticky Ask/help affordance or full-screen sheet, not buried in the page.
- Provider workspace mobile screens should avoid showing BNA school-only language.
