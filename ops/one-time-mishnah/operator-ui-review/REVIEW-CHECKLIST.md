# One Time UI Review Checklist

## Owner/Admin

- Operations opens in One Time scope.
- Left navigation shows One Time modules only.
- No BNA private parents, students, accounting, or accountability data appears.
- Decisions, parents, students, contacts, communications, live class, course,
  library, payments/trial, integrations, and settings load.

## Parent

- Parent sees only the linked TEST child.
- Next class, attendance minutes/percentage, course progress, library,
  worksheets, announcements, achievements, trial/payment state, private
  question, and support ticket paths are visible.
- Provider internal notes and other children are hidden.

## Student

- Student sees own next class, protected join readiness, minutes/percentage,
  lessons, Vimeo/manual reference, worksheet/resource, progress, achievements,
  announcements, and private question/support.
- No student bot or BNA accountability/goals UI is visible in One Time mode.

## Provider

- Provider sees schedule, availability/class media, classes, members,
  attendance, curriculum, weekly updates, questions, media/transcript review,
  publication approval, badge awards, consultations, and parent communication.

## Basic Visual Checks

- Check 390 x 844 and 1440 x 900.
- No obvious clipping or horizontal page overflow.
- Top filters remain horizontal.
- Buttons either work or explain their blocker.
- Console has no uncaught errors.
