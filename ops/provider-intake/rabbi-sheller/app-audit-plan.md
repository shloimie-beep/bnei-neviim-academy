# App Audit Plan

Audit questions:

- Does the app have parent login?
- Does it have student/member login?
- Does it have an admin backend?
- Does it have a video/Vimeo library?
- Does it have class schedule and Zoom links?
- Does it have worksheets/source sheets?
- Does it have questions/comments/threads?
- Does it have moderation?
- Does Rabbi approve or quote student/member questions?
- Does it track payment/access status?
- Does it have analytics?
- Does it have CRM/member records?
- Does it have API/export/database access?
- Which design patterns are worth copying?
- Should BNA integrate, embed, sync, copy patterns, or leave it external?

Audit outputs:

- login/access map
- data model summary
- provider participant portal mapping
- security risks
- missing access list
- integration recommendation
