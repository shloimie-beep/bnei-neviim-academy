# Credential Security Notes

Do not store secrets in Git, reports, screenshots, Telegram, or Drive folders
used for ordinary materials.

Secret-safe methods:

- Replit collaborator invite.
- GitHub collaborator invite.
- Direct account invitation.
- Password-manager shared item.
- One-time secret link.
- OAuth/connect flow.

Acceptable non-secret evidence:

- Redacted settings screenshot.
- Redacted domain/DNS screenshot.
- Redacted payment/product screenshot.
- Exported CSV without passwords/tokens.
- UI screenshots with private student/member details masked if needed.

If a secret is accidentally found, record only:

- secret type
- file/path/source where found
- mitigation needed

Do not copy the secret into a report.
