# Access Checklist

Request these by invitation or one-time secret link where possible:

- Replit/project collaborator access.
- GitHub repo collaborator access if code is in GitHub.
- App admin login or temporary admin invite.
- Read-only database/admin console access if available.
- Vimeo/video-library access or export list.
- Website/domain/DNS screenshots or delegated access.
- Payment processor/payment-link access or redacted configuration screenshots.
- Email sender/domain/account ownership details.
- GHL/CRM access only if One Time records live there.
- Publer/Buffer/social scheduling access if used.
- Member/customer CSV export.
- Questions/comments/threads export or screenshots.
- Calendar/Zoom class schedule access.
- API/export documentation if the app has it.

Do not request passwords in screenshots. Prefer:

- collaborator invite
- password-manager shared item
- one-time secret link
- OAuth/connect flow
- redacted screenshots for non-secret config
