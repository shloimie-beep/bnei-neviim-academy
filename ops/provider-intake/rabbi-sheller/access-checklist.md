# Access Checklist

Preferred access methods:

- GitHub collaborator invite for source code.
- Replit collaborator invite for the live app workspace.
- Vimeo/library admin or read-only analytics invite.
- Scoped admin login for any existing dashboard.
- One-time secret link or password-manager shared item for credentials that cannot be invited.

Do not request:

- Password screenshots.
- Unredacted API key screenshots.
- Shared root account passwords when a collaborator invite is available.

Access to request:

- Rabbi contact email before scoped login handoff.
- Rabbi WhatsApp/contact phone before any manual login link or support loop.
- Confirmation that login should be sent only after Drive/social setup is ready.
- One Time Mishnah Class Drive video-drop and social-output folder use.
- Facebook, LinkedIn, YouTube, Instagram, and WhatsApp Status account/channel
  destinations for Shloimie setup.
- Source repo or Replit project.
- Database/schema export or read-only DB connection.
- Existing parent/member login flow.
- Existing admin backend.
- Vimeo/video library and analytics.
- Payment/access tracking source.
- Calendar/Zoom setup.
- Current member/customer export.
- Current email/WhatsApp/community tooling.
