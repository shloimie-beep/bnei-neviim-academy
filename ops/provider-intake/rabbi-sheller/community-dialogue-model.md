# Community Dialogue Model

Possible One Time dialogue objects:

- class question
- member comment
- Rabbi answer
- Rabbi-approved quote
- source request
- worksheet/source-sheet follow-up
- moderation decision
- support/access issue

Rules for BNA integration:

- Provider participant dialogue is separate from BNA school accountability.
- Provider helper can see class/program materials, schedule, worksheets,
  questions, and payment/access state only for that provider program.
- Provider helper must not see BNA private student notes, goals, check-ins,
  parent communications, or school accountability records.
- Rabbi approval should gate public/member-visible question quotes.
