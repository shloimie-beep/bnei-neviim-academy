# Community Dialogue Model

Possible dialogue models:

- Private question intake to Rabbi/Shloimie.
- Anonymized class question digest.
- Moderated member posts.
- Rabbi-approved quotes from questions.
- No public forum for launch.

Default recommendation for launch:

- Use private question intake and Rabbi-facing digest first.
- Do not launch an open public forum until moderation, privacy, and access boundaries are approved.

Data boundaries:

- Provider participants are not BNA school students.
- Provider participant questions do not enter BNA student accountability.
- BNA parent/student private notes do not appear in the provider workspace.
