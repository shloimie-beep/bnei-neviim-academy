## RC-01 Artifact Status Collapsed Into Product Status

Audits, prompt packets, Product Quality Compiler validation, generated Agent Mode prompts, and zero-finding machine reports were sometimes allowed to feel like product completion. The corrective rule is now explicit in this register: artifact done is not product done.

## RC-02 Parent Closed Before Descendants

Broad One Time UI goals were closed while descendant source statements still had skipped lifecycle stages. The new matrix keeps the parent audit/compiler task separate from underlying UI product gaps.

## RC-03 Machine Pass Without Designer Closeout

The latest deployed audit reports 0 automated findings, but manual review still found mobile nav clipping, visible brand/copy inconsistency, and provider long-text containment issues. Automated checks did not model these taste/text-fit failures.

## RC-04 Evidence Registry Mismatch

`npm run ui:source-coverage` reported screenshot_files=0 while current screenshot evidence exists under the provider parity audit package. This means route/source status can drift away from actual visual proof.

## RC-05 Prompt Created But Not Run

Agent Mode proof readiness and prompt generation are not proof. The current proof-readiness state still includes not_started proof prompts.

## RC-06 External Blockers Obscured Local UI Work

External setup blockers such as Telegram chat ID, payment/provider setup, or Agent Mode proof should block only dependent tasks. They should not prevent local UI gap registration, code-prep packages, or process repair.

## RC-07 Brand Display Name Not Centralized

Durable memory says Rabbi / One Time branding, but screenshots still show OneTimeOneTime display labels in multiple user-facing places. Domain/email strings appear to have leaked into brand labels.

## RC-08 Manual Mobile Visual States Were Under-Specified

The automated visual checks caught overflow/topbar metrics but did not catch clipped nav labels where horizontal scroll/hidden content made the UI feel unfinished. The mobile state matrix needs label containment assertions.
