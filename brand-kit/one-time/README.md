# OneTimeOneTime Brand Kit

Review-safe brand kit for the shared One Time Mishnah Class build on PR #5.

This folder documents the usable palette, approved local assets, copy anchors, and guardrails for the current shared review. It does not approve live sending, live checkout, access automation, DNS, separate Railway provisioning, or external CRM writes.

## Core Files

- `colors.json`: current palette tokens.
- `assets.json`: committed asset paths and source-trace notes.
- `copy.md`: landing-page and portal copy anchors.
- `usage.md`: implementation and privacy rules.
