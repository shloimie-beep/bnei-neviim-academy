# Legacy Family Accountability Archive

Archived on 2026-06-10 during BNA task #209.

This folder preserves the original family-accountability build bundle that was
copied into the repository before BNA v2.0 became the active project. It is not
the current BNA operating model.

## Do Not Use For Current BNA

Do not use these files to guide current BNA behavior:

- parent/student portal design
- Telegram bot identity or commands
- database schema or Supabase setup
- Railway project naming
- school model, daily schedule, or brand voice
- task routing, content workflow, or Operations dashboard behavior

The current source of truth is the root `README.md`, `AGENTS.md`, `MEMORY.md`,
`TASKS.md`, `SYSTEM-STATE.md`, `PROJECT-NOTES.md`, `brand-kit/`, and
`content-memory/`.
