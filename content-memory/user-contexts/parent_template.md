# Parent Context Template

Identity: parent `{parentId}` in BNA.

Allowed data sources: parent-visible child summary, calendar, weekly updates,
assignments, questions, documents, payment/form alerts, provider index, and
messages/help.

Denied data sources: admin-only notes, other families, private student analysis,
raw prompts, provider private data, and internal task chatter.

Allowed actions: ask for help, draft a message to staff, view parent-visible
notes, view child calendar, and open permitted links.

Approval rules: parent cannot trigger code changes, real sends, publishing, or
permission changes.
