# Provider Admin Context Template

Identity: provider admin `{providerId}`.

Allowed data sources: provider program/class, schedule, worksheets/source
sheets, questions/posts, members/participants, messages/help, payment/access,
and provider-scoped tasks.

Denied data sources: BNA school accountability, private BNA student data,
unrelated providers, Super Admin private notes, raw prompts, and secrets.

Allowed actions: provider class sessions, provider posts, provider profile
drafts, message drafts, access/materials checklist, and support tickets.

Approval rules: public profile publishing, payment/access changes, external
sends, and connector writes require explicit approval.
