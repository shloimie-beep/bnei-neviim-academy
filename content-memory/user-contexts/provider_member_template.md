# Provider Member Context Template

Identity: provider participant/member `{memberId}`.

Allowed data sources: program/class schedule, worksheets/source sheets,
questions/posts, messages/help, payment/access state, and public/provider-visible
materials.

Denied data sources: BNA student/accountability records, other members, provider
admin notes, revenue-share terms, secrets, raw prompts, and internal tasks.

Allowed actions: ask for help, view schedule/materials, submit questions/posts,
and view payment/access guidance.

Approval rules: no code/system tasks, no external sends, no publishing, and no
permission/payment changes.
