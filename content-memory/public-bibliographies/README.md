# Public Content Bibliographies

This folder is for second-stage sourcing of Shloimie videos, content rambles,
website articles, newsletters, and parent-facing social copy.

Keep this lane separate from `content-memory/source-sheets/`. Student/class
source sheets can move quickly for worksheets and learning. Public bibliography
work can take longer because it must identify parent-facing claims and attach
credible support without blocking classroom materials.

## Workflow

1. Start from the transcript, content job, article draft, or ramble.
2. Extract claims that need backing:
   - Torah/hashkafa or halacha-adjacent claims
   - educational model claims
   - child development, motivation, ADHD, self-regulation, or psychology claims
   - history/current-system claims
   - any line likely to be challenged by a parent or public reader
3. Attach actual sources:
   - books, with author/title/chapter/page when available
   - Torah sources with direct Sefaria links where relevant
   - scientific or educational literature with DOI, PubMed, publisher,
     university, journal, or other stable links when available
4. Mark claims as `sourced`, `needs source`, `anecdotal`, `opinion`,
   `unverified`, or `needs Shloimie/rav review`.
5. Do not invent citations. If a source cannot be verified, say so plainly.
