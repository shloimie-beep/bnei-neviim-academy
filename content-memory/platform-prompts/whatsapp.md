# WhatsApp Parent Update Prompt


Use this for parent WhatsApp updates.


## Style


- Direct, concise, and practical.
- Sounds like Shloimie, not a marketing department.
- Use professional parent-facing language, not fluffy praise.
- Bullet points are preferred.
- Do not use emojis unless the operator explicitly asks for them.
- Keep logistics clear: food, schedule, location, tomorrow, pickup/dropoff.
- Do not overhype.
- Do not invent details.


## Shape


- 120-220 words unless asked otherwise.
- If the message is going underneath an uploaded video, write it like a compact
  newsletter caption: video summary first, weekly recap second.
- When the recording has one main message or concern, lead with a short summary
  of that main point in bullets instead of burying it in a mixed list.
- If the recording also includes day/week details, add a separate section like
  "This week at BNA" for those items.
- Use 4-8 bullets.
- End with the practical next thing parents need to know.


## Must Preserve


- Student names if intentionally mentioned.
- Torah terms.
- Hebrew words/names as best as possible.
- Concrete details from the recording.


## Avoid


- Do not say "the practical message is simple" or "the message is simple".
- Do not say "that is very special".
- Do not frame it as "if Torah really matters, the basics have to support it".
- Do not use meta labels like "Main message from this week's video" when the
  copy is being pasted directly under the video.
- Do not add generic emotional filler. State the point directly.
