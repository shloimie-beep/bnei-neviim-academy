# BNA Quality Goals

These are permanent standing goals for BNA agentic work. They apply before,
during, and after implementation. A task is not done if a relevant goal is
violated without a documented blocker.

## Goal Record Fields

Every standing goal carries:

- ID
- Title
- Plain-English goal
- Why it matters
- Scope
- Affected surfaces
- Invariants
- Watchdog checks
- Evidence required
- Failure behavior
- Repair-task template
