## Objective

Make the public website visually coherent, connected, responsive, accessible, and consistent with the owner’s repeated direction.

Known defects include:

- unintended space between the top toolbar/header and hero;
- unreadable selected horizontal category/tab state;
- public navigation changes not consistently visible;
- placeholder/generic content;
- stale footer content;
- inconsistent spacing, buttons, and active states;
- mobile overflow or menu awkwardness;
- branch/live differences.

## Step 2 — Header-to-hero repair

Find the exact cause of any blank strip:

- body margin;
- header margin/padding;
- hero margin;
- margin collapse;
- hidden banner;
- sticky offset;
- image inline baseline;
- breakpoint rule;
- stale CSS;
- wrong deployed bundle.

Acceptance test:

```text
abs(header.getBoundingClientRect().bottom -
    hero.getBoundingClientRect().top) <= 1
```

Run at every required viewport.

Ensure:

- sticky header does not cover hero content;
- no accidental whitespace;
- no content jump after fonts/images load;
- no mobile-only gap.

## Step 3 — Horizontal active tabs and filters

Find every public:

- category tab;
- subcategory tab;
- filter chip;
- active nav item;
- horizontal scroller.

Acceptance:

- WCAG AA contrast;
- normal text contrast at least 4.5:1;
- active state is not conveyed by color alone;
- `aria-current`, `aria-selected`, or `aria-pressed` is correct;
- keyboard focus is clearly visible;
- hover/focus/active/disabled are distinct;
- selected text is readable at all viewports;
- horizontal overflow is intentional and usable;
- tabs do not clip or disappear.

Add computed-style assertions, not screenshot-only tests.

## Step 4 — Public navigation integrity

Ensure the public header and footer expose the intended information architecture.

Audit:

- BNA/School;
- Families;
- Service Provider Directory;
- One Time;
- Blog;
- FAQ;
- registration/apply;
- portal logins.

Requirements:

- no dead links;
- no duplicate labels with different destinations;
- active state is correct;
- mobile menu contains the same legitimate destinations;
- portal login links use canonical routes;
- Operations is not accidentally promoted as a general public destination unless intentionally approved;
- current page is understandable;
- footer provides a complete secondary route map.
