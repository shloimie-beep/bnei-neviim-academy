For mixed recordings, do not force the whole recording into one lane. Break it into sections and route each section separately.

Private rules:
- If private_meeting or private_student_detail is detected, do not put raw body text in GitHub.
- Use stable labels/hashes.
- Store only summary, category, owner, next action, and private Drive/app pointer.
- Create a review item if the system cannot safely classify.

Student matching rules:
- Do not auto-merge ambiguous student names.
- Do not create or suggest cross-student writes without confidence evidence.
- Record:
  - matched stable student label;
  - confidence;
  - alias evidence summary;
  - ambiguity reason;
  - next action.

Task extraction rules:
- Create task candidates, not live production tasks, unless the active run explicitly authorizes task creation.
- Every task candidate must include:
  - title;
  - owner;
  - category;
  - priority;
  - depends_on;
  - related source/job;
  - notes;
  - privacy classification;
  - confidence.

Question extraction rules:
- Preserve the question meaning.
- Do not commit private student identity or raw private phrasing if sensitive.
- Deduplicate repeated question echoes.
- Link each question candidate to recording/job/section.
- Record whether it is:
  - classroom question;
  - content question;
  - parent-facing FAQ;
  - private student support;
  - needs Rabbi review.
