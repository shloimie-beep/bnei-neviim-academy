# Service Provider Classrooms Memory

- Service-provider flows should connect public provider pages, provider index,
  provider join, provider portal, classroom/community setup, billing/plans, and
  safe access controls.
- Classroom setup is first-party/internal unless a later connector is explicitly
  approved.
- Each service provider has its own scoped classroom/content/community pipeline.
  Shared platform fixes can be promoted through reusable components, route/
  action contracts, helper contracts, visual standards, and workspace-scope
  enforcement, but provider classroom/content/community records must not merge
  into BNA Academy or another provider without an explicit cross-workspace link.
- Provider helper actions should create local drafts/tasks first.
- Relevant standing goal: `GOAL-CORE-014`.
