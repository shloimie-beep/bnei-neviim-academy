# Design References Memory

- Screenshots, Replit apps, website captures, brand notes, and `make it look
  like this` references must be saved under `ops/design-references/` before
  implementation.
- Do not rely on memory of screenshots.
- Every design-reference package must include source, screenshot index,
  extracted tokens, component patterns, current config comparison, and
  implementation mapping.
- If a referenced screenshot or Replit app is missing, create a design-reference
  gap blocker instead of guessing.
